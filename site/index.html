nsh-widgets

Home-screen widgets for Native Shell (NSH) apps.

The app describes each widget once, as a tree of primitives written in TSX or JSON, and feeds it data. A generic renderer draws the tree natively: SwiftUI in a WidgetKit extension on iOS and macOS, RemoteViews on Android. Widget buttons change the data without the app.

Status: 0.1.0

Install with nsh add github:SuperNSH/widgets@^0.1. Needs NSH main at or after 5aa56b19, or the nightly; the 0.6.0 and 0.6.1 releases cannot package widget extensions.

Primitives

Col, Row, Text, Spacer, Button, Link, Progress, Bars, Icon, Timer, Clock, Toggle, Rotate, styled with a Tailwind subset and light and dark theme tokens, with 21 shared icons and gradients on every platform. Buttons run inc:key, dec:key, toggle:key or open a URL.

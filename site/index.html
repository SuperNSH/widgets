nsh-widgets

Home-screen widgets for Native Shell (NSH) apps.

The app describes each widget once, as a tree of primitives written in TSX or JSON, and feeds it data. A generic renderer draws the tree natively: SwiftUI in a WidgetKit extension on iOS and macOS, RemoteViews on Android, QML in a generated KDE Plasma widget. Widget buttons change the data without the app.

The same trees drive iOS Live Activities. Widgets can let the user pick a value, draw lists, and an app can add iOS 18 Control Center controls and Android Quick Settings tiles bound to a widget's data.

Install with nsh add github:SuperNSH/widgets@^0.2. Needs NSH main at or after 5aa56b19, or the nightly; the 0.6.0 and 0.6.1 releases cannot package widget extensions.

Primitives

Col, Row, Text, Spacer, Button, Link, Progress, Bars, Icon, Timer, Clock, Toggle, Rotate, List, styled with a Tailwind subset and light and dark theme tokens, with 21 shared icons and gradients on every platform. Buttons run inc:key, dec:key, toggle:key or open a URL.
